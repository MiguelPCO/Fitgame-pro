## Principios de Programación

### Volumen Semanal por Grupo Muscular
```
Principiante: 10-12 sets/semana
Intermedio:   12-18 sets/semana
Avanzado:     18-25 sets/semana

Máximo por sesión: 10 sets por grupo
(más allá = junk volume)
```

### RPE (Rate of Perceived Exertion)
```
RPE 6  = 4 reps en reserva (warm-up)
RPE 7  = 3 reps en reserva (técnica)
RPE 8  = 2 reps en reserva (trabajo efectivo)
RPE 9  = 1 rep en reserva (sets pesados)
RPE 10 = Fallo muscular (usar con moderación)

Target típico hipertrofia: RPE 7-9
```

### Rangos de Repeticiones
```
Fuerza:      1-5 reps   @ RPE 8-9
Hipertrofia: 6-12 reps  @ RPE 7-9
Resistencia: 12-20 reps @ RPE 7-8

Todos los rangos pueden producir hipertrofia
si se lleva cerca del fallo.
```

### Tiempos de Descanso
```
Compuestos pesados: 2-3 min (squat, deadlift, bench)
Compuestos medios:  1.5-2 min (rows, press)
Aislamiento:        60-90 seg
Supersets:          Sin descanso entre ejercicios
```

### Splits Recomendados por Frecuencia
```
3 días: Full Body (A/B/A - B/A/B)
4 días: Upper/Lower (U/L/U/L)
5 días: Upper/Lower/Push/Pull/Legs
6 días: PPL x2 (Push/Pull/Legs/Push/Pull/Legs)
```

## Patrones de Movimiento

### Must-Have por Sesión
```
Push: Press horizontal + Press vertical
Pull: Row horizontal + Pull vertical
Legs: Hip hinge + Knee dominant + Isolation
```

### Ejercicios Tier List
```
S-Tier (fundamentales):
- Squat, Bench Press, Deadlift, Overhead Press
- Pull-ups, Barbell Rows, Romanian Deadlift

A-Tier (muy efectivos):
- Incline Press, Leg Press, Hip Thrust
- Cable Rows, Lat Pulldown, Lunges

B-Tier (accesorios útiles):
- Flyes, Lateral Raises, Curls, Tricep Extensions
- Leg Curls, Leg Extensions, Calf Raises
```

## Progresión de Cargas

### Double Progression (recomendado para app)
```
1. Empieza en el bajo del rango (ej: 8 reps)
2. Cada sesión intenta +1 rep
3. Al llegar al tope del rango (12 reps), sube peso
4. Reinicia en el bajo del rango con nuevo peso
```

### Autoregulación por RPE
```
Si RPE < target: Sube peso próxima serie
Si RPE = target: Mantén peso
Si RPE > target: Considera bajar peso o descanso extra
```

## XP y Gamificación (Validación)

### Acciones que Merecen XP
```
✅ Completar set (cualquier RPE)
✅ Alcanzar target RPE (bonus)
✅ PR de peso o reps (bonus grande)
✅ Completar sesión completa (bonus)
✅ Mantener streak (multiplicador)
```

### Acciones que NO Deben Penalizar
```
✅ Descanso programado (no rompe streak)
✅ Sesión parcial (XP proporcional, sin penalización)
✅ RPE bajo en día difícil (autoregulación válida)
✅ Reducir peso por fatiga (decisión inteligente)
```
